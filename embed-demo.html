Embed

Use the finder on another site

Add this markup. The script loads the catalog from this site, draws inside a shadow root, and does not restyle the host page.

<div id="movie-finder"></div>
<script src="https://mkpworks.github.io/movie-finder/embed.js" defer></script>

Optional attributes: data-theme (light or dark), data-accent (a hex color), and data-height (a max height). data-genre, data-decade, data-tag, data-kind, data-bonus (yes or no), and data-director, data-cast, data-writer, data-composer, data-cinematographer, and data-producer preset those filters. Any element with data-movie-finder mounts too. Call MovieFinder.mount(element, options) for the same options in script.
